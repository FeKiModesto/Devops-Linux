# 📘 Aula 03 - Configuração de ambiente e execução Java

Nesta aula foi realizada a instalação do Java na máquina virtual Linux e a execução de um programa simples via terminal.

---

## 🛠️ Etapas realizadas

### 🔄 Atualização do sistema

---

### ☕ Instalação do Jaa

sudo dnf install java-21-openjdk java-21-openjdk-devel -y

---

### 📁 Criação do projeto

- mkdir java
- cd java

---

### 📄 Criação do prograa

nano HelloWorld.java

---

### ⚙️ Compilação e execução

- javac HelloWorld.java
- java HelloWorld

---

## 📊 Resultado

Programa executado com sucesso exibindo mensagem no terminal.

---

## 🎯 Objetivo

Configurar o ambiente Linux e executar aplicações Java utilizando o terminal.
