# Aula 04 - Criação de conta na Oracle Cloud

Nesta aula foi realizada a criação de uma conta na Oracle Cloud, plataforma utilizada para provisionamento de máquinas virtuais (VMs) na nuvem.

## Etapas realizadas

### Acesso ao site
- Acesso ao site oficial da Oracle Cloud

### Criação da conta
- Preenchimento dos dados pessoais
- Verificação de identidade
- Finalização do cadastro

## Resultado
Conta criada com sucesso na Oracle Cloud, pronta para utilização na criação de máquinas virtuais.

## Objetivo
Preparar o ambiente em nuvem para futuras atividades práticas, como criação e configuração de máquinas virtuais.
